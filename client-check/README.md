# Аудит клиентского компьютера (Практика 8, часть 2)

## Выбранные категории базового ПО
Для проверки базового офисного рабочего места были выбраны следующие категории:
1. **Офисный пакет** (Office, LibreOffice, МойОфис) — необходим для работы с документами.
2. **Браузер** (Chrome, Firefox, Edge, Яндекс) — доступ к внутренним системам и интернету. *Примечание: Edge есть в любой Windows, поэтому его наличие не гарантирует настроенное рабочее место.*
3. **Чтение PDF** (Acrobat, Foxit, SumatraPDF) — для просмотра документации.
4. **Архиватор** (7-Zip, WinRAR, WinZip) — для работы с вложениями в почте.
5. **Антивирус** (Defender, Kaspersky, ESET, Dr.Web) — базовая безопасность.

## Признаки излишнего ПО
Скрипт проверяет наличие программ по ключевым словам в названиях:
- **Игры:** Steam, Epic, GOG, Origin, Ubisoft, Battle.net, Riot, слова game/gaming.
- **Торренты:** torrent, uTorrent, BitTorrent, qBittorrent, Vuze.
- **Мессенджеры:** Discord, Telegram, WhatsApp, Viber, Skype (носящие рекомендательный характер, так как могут быть рабочим инструментом).
- **Развлечения:** Wallpaper Engine, OBS, Soundpad.

## Как проверялась работоспособность логики
1. **Ветвь "Базовое ПО":** Скрипт успешно находит установленный архиватор (7-Zip) и выводит его название с отметкой `[OK]`. Если временно убрать ключевое слово "7-Zip" из кода, скрипт выдает рекомендацию `[!] Не обнаружен архиватор`.
2. **Ветвь "Излишнее ПО":** При наличии установленного Steam или Discord, скрипт выводит их в раздел рекомендаций к проверке.
3. **Обработка ошибок:** Если переменные не считываются, скрипт не выводит пустую строку, а пишет "Не удалось получить данные".

## Ограничения решения
- Скрипт не умеет определять дату последнего запуска программы (в Windows это невозможно сделать надежно через cmd). Логика построена на сверке с эталонными списками.
- Список излишнего ПО является *рекомендацией к проверке*, а не строгим приказом к удалению, так как политики безопасности в разных компаниях отличаются.
