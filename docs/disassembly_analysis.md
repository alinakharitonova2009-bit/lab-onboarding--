# Дизассемблирование

## Восстановленный код на Python
```python
total = 0
for i in range(1, 11):
    total += i
```
## Пояснение логики
Код на ассемблере представляет собой цикл. Переменная `-4(%rbp)` выступает в роли аккумулятора (суммы, `total`), а `-8(%rbp)` — в роли счетчика (`i`). 
Инструкция `jle .L3` (jump if less or equal) проверяет, что счетчик меньше или равен 10, и если это так, цикл продолжается. В итоге код считает сумму чисел от 1 до 10.
