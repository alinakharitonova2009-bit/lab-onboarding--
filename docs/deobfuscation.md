# Деобфускация

## 1. Расшифрованная строка
`import os; os.system('rm -rf /')`

## 2. Анализ угрозы
При выполнении этого скрипта будет вызвана системная команда rm -rf /. Эта команда рекурсивно и без запроса подтверждения удаляет **все файлы на жестком диске** (начиная с корневой директории /), что приведет к полному уничтожению операционной системы и потере всех данных.

## 3. Методы защиты
* Запрет использования небезопасных функций (`exec`, `eval`) для обработки динамических данных.
* Использование антивирусов и систем статического анализа кода.
* Запуск потенциально опасного кода в изолированной среде (песочнице/Docker).
